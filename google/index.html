Technical questions
Walk me through migrating a customer from on-prem to cloud. (★ mentor)Discover (inventory, dependencies, cost) → Plan (business case, approach per app, waves) → Foundation (landing zone, network, IAM) → Migrate (pilot, then waves, cutover with rollback) → Optimize (rightsize, modernize). Give your SAP and DMV examples.
Design something like Instagram and scale it globally. (★ mentor)Ask about scale first. Global load balancer + CDN → stateless services → object storage for media → database (Spanner if global) → cache → async queue for processing. Then cover failure and cost.
The customer wants to host in China, but there's no cloud region. (★ mentor)Ask about legal rules first. Use a local partner cloud inside China, a control plane in Hong Kong or Singapore, and comply with licensing and data-export rules.
How do you modernize a mainframe?Options: rehost, automated refactor, rewrite, retire. Cover data (DB2 → PostgreSQL), batch jobs, and parallel-run testing. Then your DMV numbers.
Design disaster recovery for 4-hour RTO / 1-hour RPO. Now make it 15 minutes.Backup-restore → pilot light → warm standby → active-active. Each step costs more. Use your Medicaid and SAP numbers.
Which database would you choose, and why?Cloud SQL (standard relational), AlloyDB (high-performance Postgres), Spanner (global and consistent), Bigtable (huge throughput), Firestore (documents).
The cloud bill rose 40%. What do you do?Find the top services by cost, rightsize, commit discounts, Spot for batch, storage tiers, labels and budgets. Then your $600K story.
Agentic AI (★ both mentors)
Why MCP instead of a normal API?MCP is a standard protocol (JSON-RPC) that lets any agent discover and call tools with a schema. A REST API needs custom code for each app. MCP wraps APIs; it doesn't replace them.
What is A2A?A protocol for agents talking to other agents. MCP is agent-to-tool; A2A is agent-to-agent.
How do you take an agent to production?Develop (ADK + tools) → deploy (Cloud Run or Vertex AI Agent Engine) → scale (quotas, caching, small vs large model routing) → govern (least-privilege tools, human approval for risky actions, logging).
How do you evaluate an agent?A test set of tasks. Measure success rate, correct tool calls, latency and cost. Re-run on every change.
System 1 vs System 2 models?Fast single-pass models vs slower reasoning models. Route easy requests to fast ones, hard ones to reasoning ones.
General Cognitive Ability
A dashboard was built for sales, but nobody uses it. Drive adoption. (★ asked per Diyasini)Ask who it's for and what decision it supports → interview 5 users to find why → co-design fixes with 2 champions → put it where they already work → have leaders use it weekly → track weekly active users.

Presentation practice case

"A state agency runs a 30-year-old mainframe for licensing (300 requests/second peak). Modernize within 24 months, keep personal data in-state, cut costs 30%."

8 slides: customer goals → assumptions → current pain → target architecture → migration phases → cost and value → risks → next steps (PoC scope and success criteria).

Expect these objections: too expensive (show 3-year cost), security (encryption, data perimeter, compliance), lock-in (containers, Terraform), no skills (training, partners), too slow (phased waves).
